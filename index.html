Правила игры

  1. Разделитесь на команды и по очереди выбирайте категорию и стоимость вопроса.
  2. На обсуждение можно отвести 20–30 секунд. Ответ озвучивает представитель команды.
  3. Ведущий открывает правильный ответ и отмечает результат.
  4. За верный ответ выбранная команда получает баллы. За неверный ответ баллы не начисляются.
  5. Каждая ячейка используется только один раз. Побеждает команда с наибольшим количеством баллов.

Ведущий может разрешить другой команде ответить после ошибки первой команды.
